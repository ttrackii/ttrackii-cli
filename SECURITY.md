# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
through GitHub's **Report a vulnerability** button on this repository's
Security tab, or email hello@ttrackii.com with "Security" in the subject.

Include the CLI version (`ttrackii --version`), your operating system, and steps
to reproduce. We aim to acknowledge reports within three business days.

## Scope

This repository covers the `ttrackii` command-line client: credential storage,
the device login flow, and how it talks to the ttrackii API. Issues in the
ttrackii web service itself are also welcome through the same channels.

## Supported versions

Only the latest released version receives security fixes.
